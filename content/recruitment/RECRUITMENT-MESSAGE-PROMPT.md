# Reusable AI Prompt — Real Estate Agent Recruitment Messaging

Copy everything in the box below into any AI assistant (Claude, ChatGPT, etc.).
Fill in the `[bracketed]` fields first for best results — or leave them and the AI
will insert clearly-marked placeholders for you to complete later.

---

## ▶ THE PROMPT (copy from here)

```
You are an expert real estate recruiting copywriter. Write a complete, multi-channel
recruitment messaging package designed to attract BOTH newer/about-to-be-licensed agents
AND experienced agents to join a real estate team.

== TEAM CONTEXT ==
- Team name: The Matt Smith Team
- Brokerage: RE/MAX
- Market: Cedar Rapids / Eastern Iowa
- Website: mattsmithteam.com
- Recruiter/point of contact: Matt Smith — [phone], [email]
- Unique advantage: a custom-built in-house technology platform ("Real Estate Command
  Center") that handles lead follow-up, transaction deadlines/checklists, done-for-you
  marketing, and a daily action plan — most local teams do not have this.
- Also provided to agents: team-generated leads, hands-on coaching/mentorship,
  professional marketing, and admin/transaction-coordination support.

== NUMBERS TO INCORPORATE (use if provided; otherwise insert [bracketed] placeholders) ==
- Commission split / cap structure: [fill in]
- Lead volume or % of business from team-provided leads: [fill in]
- Team production / transaction count for social proof: [fill in]
- Agent testimonials, especially "I was new and…" or "I switched brokerages and…": [fill in]

== CORE POSITIONING PRINCIPLES (follow all of these) ==
1. Lead with the AGENT'S pain, not the team's trophy case. Open by naming the frustration
   agents already feel (e.g., being handed "the keys and good luck" with no system or support).
2. Make the technology platform the unfair advantage — describe it concretely so the offer
   feels real and impossible for competitors to copy.
3. Speak to two audiences in one message: newer agents hear "training + leads + a playbook";
   experienced agents hear "leverage + less chaos + more take-home." Include a short
   "Who this is for" section that lets each reader self-select.
4. Sell the NET, not the split. Reframe commission as take-home value once leads, tech,
   marketing, and admin support are included — and make it a conversation, not a flyer number.
5. Make the ask tiny: "one honest conversation," "compare notes," "no pitch, no pressure."

== TONE ==
Warm, confident, human, and direct. Zero corporate jargon. Sound like a successful local
agent who genuinely wants to help, not a hard-sell recruiter. Light, tasteful emoji use is
fine in short-form/social pieces only.

== DELIVERABLES (produce ALL of these, clearly labeled) ==
1. 4 subject-line options for the flagship message.
2. The flagship recruitment message (long-form letter/email): strong opening hook, a
   scannable list of 5–6 concrete benefits with icons/bold labels, a "Who this is for"
   section (newer agent vs. experienced agent), and a low-pressure call to action with
   full signature (name, team, brokerage, city, phone, email, website).
3. A cold text/DM version (warm, ~2–3 sentences).
4. A text version aimed specifically at a newer/about-to-be-licensed agent.
5. A LinkedIn/social recruiting post with a bold headline, checkmark benefit list, CTA,
   and relevant hashtags.
6. A 15-second voicemail script.
7. A one-line follow-up email (for after no response), with subject line.
8. A short "Why this message works" section explaining the positioning choices.
9. A pre-send checklist of the [bracketed] items the user still needs to fill in.

Keep any unknown specifics as clearly-marked [brackets] rather than inventing facts
(never fabricate splits, lead counts, or production numbers).
```

## How to customize this prompt
- **Different team/market?** Swap the TEAM CONTEXT block — everything else still works.
- **One channel only?** Delete the deliverables you don't need (e.g., keep only #2).
- **Have real numbers?** Replace the `[bracketed]` items in the NUMBERS section before sending
  so the AI weaves them in instead of leaving placeholders.
- **Want a flyer, landing page, or video script instead?** Add it as a new deliverable line,
  e.g. "10. A one-page recruiting flyer layout" or "11. A 30-second recruiting video script."
- **Want it sharper/softer?** Adjust the TONE block.
